# 开发用 HLTV 浏览器中继

这是 0.2 开发阶段保留的可选诊断工具。它在电脑上的独立 Edge 配置中读取 HLTV 公开页面，再通过 USB 把页面内容传给 Android 自己的解析器。当前 RushB 已有手机独立读取路径，模拟器验收范围见 [验证记录](../../docs/VALIDATION.md)；此工具不是安装或运行手机版的前提。

## 启动与连接

需要 Node.js、Microsoft Edge，以及 Android SDK Platform Tools。项目固定 Playwright 1.64.1，使用系统 Edge，无需下载额外浏览器。

在项目根目录运行：

```powershell
cd tools/hltv-relay
npm ci
npm start
```

另开终端，在连接并授权调试的 Android 设备上转发端口（多设备时加入 `-s 设备序列号`）：

```powershell
adb reverse tcp:8765 tcp:8765
```

在 Android 应用的“我的 → 数据连接”启用“使用电脑中继”，将项目根目录 `.local/relay/token.txt` 中的 64 位令牌填入，然后保存。返回“赛事”点击刷新。比赛详情点击“加载完整详情”，随后可从阵容或选手数据打开档案。USB 重连或设备重启后可能需要再次执行 `adb reverse`。

服务首次请求时会打开自己的 Edge 窗口。验证页面如果要求人工操作，请在该窗口自行完成，之后重试。不要关闭该窗口中的目标页面。服务不会读取日常浏览器的 Cookie、账号或配置。

停止服务使用运行它的终端中的 Ctrl+C；端口转发可用 `adb reverse --remove tcp:8765` 移除。

## 访问与缓存

- 只监听电脑的 `127.0.0.1:8765`，没有局域网监听。
- 每个请求要求随机令牌；拒绝网页跨域请求和任意代理目标。
- 仅允许指定 HLTV 公开资料路径。页面重定向必须仍对应原比赛/选手编号。
- 单次读取、至少 3 秒请求间隔、120 秒页面缓存；验证失败或限速后暂停请求。
- 传输原采集时间；重复使用中继缓存时不会生成“新的”采集时间。
- `.local/relay/` 保存独立浏览器配置、令牌，已被 Git 忽略；不要上传或分发这些文件。
- Android 只对 USB 本机回环地址允许明文 HTTP，其他来源使用 HTTPS；令牌保存在应用私有偏好且不启用应用备份。

手机断开电脑时，可以查看之前成功读取的本地资料。更新失败会提示缓存可能过期；这不代表比分仍是实时的。该方案已经验证本机正常 Edge 会话可读取比赛列表、普通赛果列表、比赛详情与选手档案，但不能保证其他网络或未来站点验证策略下始终可用。

日期筛选的赛果页面在本机测试中仍会触发验证。近期赛果优先使用普通 `/results` 页，其返回范围有限；不要把未返回的历史比赛视为不存在。RSS、在线赛事日历和其他详情页不在本轮中继端到端验收范围内。

## 测试

```powershell
npm test
```

测试覆盖允许的路径、严格令牌匹配、重定向编号和日期筛选保留规则。Android 项目另有真实页面解析与缓存、持久化测试。
