# RushB 开发路线

当前版本为 0.10.6。实际通过的检查和未验证范围见 [验证记录](VALIDATION.md)，完整功能概览见 [项目说明](../README.md)。

## 已完成的主要能力

- 手机独立移动 JSON 与网页读取、身份和结构校验、失败冷却、原始时间保留及本机缓存恢复。
- 比赛分析、七图 BP、Both／T／CT、选手头像、对位矩阵、局内比分与地图胜场。
- 重点赛事月历、参赛队伍、赛事概览、每日赛程及支持的分组／对阵结构。
- HLTV／VRS 分开的排名与赛区，战队和选手资料、荣誉、近期与未来比赛及相关新闻。
- 网页月度新闻、封面、原生正文、离线恢复及已读资料搜索。
- 深浅主题、跟随系统、透明队标、紧凑统计、固定／悬浮导航、拖动选择和统一外观设置。

## 优先补齐

1. **真机与来源稳定性**：目前主要验收在 Android 16 x86_64 模拟器。补做 ARM64 真机 Wi-Fi／移动网络、冷启动、断网恢复与图片读取；分别记录挑战、403、429 和完整性要求，不用一次 200 推断长期成功。
2. **数据解释**：核实战队胜率、冠军、选手长期 Rating 的周期和样本；来源未明确时保持未知，不猜测“近三个月”或“生涯”。本场数据和长期数据不能混用。
3. **历史与分页**：验证更早比赛、相关新闻后续分页、转会履历和长期统计区间的真实契约。
4. **赛事覆盖**：补充更多分组类型、直播／录像入口，以及 LIVE、延期、取消和待定队伍样本；重点赛事继续按 [明确级别](EVENT-TIERS.md) 筛选。
5. **图片与可用性**：少数赛事小图标在浅底仍偏淡，优先寻找来源实际提供的合适版本。继续检查较窄屏幕、大字体、入口可发现性和长列表。
6. **发布准备**：开发者签名、正式构建体积、启动性能、内存及浏览器引擎安全更新。公开发布前补齐真实设备验证。

## 开发原则

数据来源、统计口径、更新时间和测试环境必须明确。失败不能覆盖成功缓存，缺失值不能当零，过期比分不能标为实时；不导入官方凭据或导出用户会话。涉及访问限制时使用已有恢复入口并尊重冷却。

功能分支在完成验证后及时合并到 main，确认合并后清理。仓库工作流程见 [贡献规则](../CONTRIBUTING.md)。
