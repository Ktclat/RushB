## 实际修改

1. **透明队标**：移除队标与赛事图标组件额外绘制的灰色底板。透明纯黑／纯白图标按所在表面调整明暗，彩色及双色图标保留图案颜色，原图片与缓存文件不改写。浅色优先复用同一战队 ID 的已取得排名图标，失败可回退原图；不推造 CDN 地址、不删除签名参数。地图 BP 的图像底板单独按深色表面处理。
2. **浅色层级**：改为中性浅灰底、白色面板、较轻描边和深蓝选中态。比赛筛选的已选项有勾选和实色背景；排名改为中性边框加赛区色侧边，保留地区文字、升降箭头及灰色 0。相同“待更新”状态在比赛行中采用一致位置。
3. **外观设置**：统一为名称、当前值、箭头组成的设置行；“显示”管理主题，“导航”管理固定／悬浮导航和启动页。点击整行打开单选面板，选中项有圆点和整行高亮；关闭不修改设置，选定后立即保存并关闭。
4. **资料与数据布局**：战队身份区收紧，排名与教练并排，三个统计项同排，五名队员继续同排。统计表保留六列同屏，增加列间距、轻分隔线与表头底色，不引入横向滚动；姓名保持单行适配。

## 独立意见处理

| 意见 | 处理 |
| --- | --- |
| F1 筛选选中态不明确 | 增加勾选、实色背景和文字粗细差异，补拍默认与欧洲＋Tier 1 两种状态。 |
| F3 同类比赛状态位置不一致 | 时间、BO、状态保持同一顺序，过期比分的原更新时间继续保留。 |
| F4 排名整圈赛区描边过重 | 改为单侧色边，保留用户要求的赛区标识及灰色排名变化 0。 |
| F5 战队身份区和统计区偏松 | 压缩重复身份区域，排名／教练与三项统计分别横向排列。 |
| 复审：黄色 Vitality 在浅底过淡 | 浅色页面复用同队已取得的深色图标版本，保留原图回退。 |
| 复审：统计数值和表头相邻过近 | 增加双侧数字列间距与列分隔线；保持六列及完整数值，窄屏测试复查。 |
| F2 战队胜率、冠军、Rating 的统计周期未显示 | 本轮未猜测来源缺失的周期，仍为已知限制；不把比赛统计的 Rating 版本当作战队档案的统计范围。 |
| F6 悬浮导航经过中途列表行 | 遵循用户要求保留导航周围透明和可触达，末项通过滚动检查；没有改为整块不透明底栏。 |
| F7 顶栏新闻图标、排名持平 0 | 保留图标式工具栏及其无障碍名称；灰色 0 是用户明确要求，未替换为破折号。 |
| R3 局部赛事标识浅底偏淡 | NODWIN、PGL 的小赛事标识仍有细节偏淡，赛事名称清楚。当前没有取得适合浅底的对应版本，保留原图，不重新加通用灰底或强制染色。 |

排名第 253 项、赛事折叠末组、展开后的最后两场与赛程最后一张卡，均已实际滚动并确认可完整显示在悬浮导航上方。对应证据为最终截图 15、16、24、25。独立模型复审了 22 张最终截图；赛事详情、新闻和冷启动补图 19、20、23 另由主代理实际查看。
