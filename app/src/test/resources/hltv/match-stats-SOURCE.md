# Complete map/side statistics fixture

`match-stats-2026-10-18.html` was reduced from the existing normal-browser capture `output/playwright/hltv-match.html` of https://www.hltv.org/matches/2399415/falcons-vs-betboom-thunderpick-world-championship-2026 on 2026-10-18.

It retains the published map results, full map tabs, 24 statistics tables (All / Anubis / Dust2 / Mirage × Both / T / CT × two teams), and player identity photos. Scripts, styles, iframes, form controls, SVG decorations, and event-handler attributes are removed. Data values, tab IDs, labels, and source links are not rewritten. The original browser capture predates the present parser implementation.

The fixture is for offline parser regression. It does not supply live or demo results to the application. Third-party source content retains its original ownership; the repository's code license does not change that ownership.
